# 아트 디렉션 — 2D 카툰 전환

이 문서는 코드 주석에서 참조하는 정본이다. GDD v1.0 §15(아트 디렉션), §16(VFX)의
"어떻게"를 채우는 문서이며, 스위치 세대 커비 시리즈를 조사해 얻은 원칙을 근거로 삼는다.

## 조사 근거

닌텐도 "Ask the Developer" 인터뷰와 개발사 코멘트에서 확인한 것:

1. **셀셰이딩은 분리를 위한 것이다.** 『별의 커비 Wii 디럭스』는 원작의 일반 셰이딩을
   셀셰이딩으로 바꾸면서 캐릭터 외곽선을 두껍게 했다. 목적은 "커비와 적을 아름다운
   배경으로부터 구분해, 화려함에도 불구하고 액션이 산만해지지 않게" 하는 것.
   → 우리 게임의 최우선 판독 대상은 숫자와 미개봉 타일이므로 동일 원리를 그대로 쓴다.

2. **inverted hull은 겹침 부위에서 깨진다.** 개발진이 직접 밝힌 문제:
   "전통적으로 쓰이는 inverted hull 기법만 사용하면 신체 부위가 겹치는 곳에서
   외곽선이 깨진 것처럼 보인다."
   → 우리는 모든 메시가 **중심 정렬된 프리미티브**라는 점을 이용해, 법선이 아니라
   *오브젝트 중심에서 바깥으로* 확장한다. 하드 엣지를 건너도 방향이 연속이므로
   헐이 찢어지지 않는다. `shaders/outline.gdshader` 참조.

3. **폐허를 공포로 만들지 않는다.** 『디스커버리』 개발진은 버려진 폐허가 호러처럼
   보이는 문제를 겪었고, "밝은 파란 하늘과 풀·꽃 같은 화사한 식물"을 넣어 커비의
   톤과 섞었다고 밝혔다. 폐허는 쇠락이 아니라 "한때의 번영과 즐거움"을 보여주는
   "자연과 어우러진 아름다운 장소"여야 한다.
   → 협곡 바닥에 강을 넣고, 교각마다 꽃 달린 덩굴과 깃발을 걸고, 바위 선반에
   야자수를 심었다. 다리는 버려진 게 아니라 자연에 안긴 것이다.

4. **난이도에 따라 색이 이동한다.** 부드러운 핑크·블루에서 시작해 후반으로 갈수록
   강한 레드·블랙으로 옮겨간다.
   → `BackdropDirector.SKY_TOP` / `SKY_HORIZON` / `SUN_COLOR` 5단계 팔레트가
   Act 전환마다 천천히 보간된다. 진행도 게이지 없이 진행감을 준다.

5. **카메라가 진행 방향의 랜드마크를 보여준다.** "이쪽이 진짜 길이다"를 카메라가
   말해준다.
   → 오프닝은 협곡을 따라 Sun Gate를 정면으로 보는 establishing shot으로 시작하고
   (`CameraDirector.View.OPENING`), 공중 2박(정점)에서 다음 다리와 목적지를 보여준다.

## 적용 규칙

### 판독 위계 (GDD 15.3)
```
숫자 > 미개봉 타일 > 장애물 > 캐릭터 > VFX > 배경
```
이 순서가 **채도**와 **선 굵기** 양쪽에 그대로 반영된다.

| 대상 | 채도 | 잉크 굵기(px) |
| --- | --- | --- |
| 갑판·미개봉 타일·캐릭터 | 최고 | 2.6 |
| 근경 바위·잎 | 중 | 1.6 |
| 중경 메사·수도교 | 낮음 | 1.2 |
| 원경 벽·협곡 바닥·물 | 최저(라벤더로 수렴) | 0 |
| 구름·모래 리본 | — | 0 |

### 조명
셀셰이딩은 감쇠 뒤에 숨을 곳이 없다. 태양 0.72 + 필 0.12 + 앰비언트 0.22 ≈ 1.06으로
합을 1 근처에 묶어, 지정한 albedo가 화면에 거의 그대로 도착하게 한다.
톤매퍼는 LINEAR(white 1.0). SSAO는 끈다 — 평면감을 죽인다.

그림자는 곱하지 않고 **밴드 하나로 흡수**한다(`toon.gdshader`의 `shadow_depth`).
곱하면 넓은 평면에서 섀도우맵 아크네가 새까만 얼룩으로 터진다. 커비 리메이크도
같은 판단을 했다("더 은은하고 보기 좋은 그림자").

### 카툰 VFX 문법 (GDD 16)
효과는 **자라고 줄어드는 형태**로 만든다. 페이드아웃하는 반투명 텍스처가 아니라,
부풀었다가 사라지는 불투명한 뭉게구름이 카툰 연기다. 셀셰이딩에는 녹아들 소프트
엣지가 없기 때문이기도 하다.

- `_star` — 원뿔이 방사하는 코믹 폭발. 3프레임에 튀어나오고 훅 사라진다.
- `_puffs` — 공 3개가 겹친 뭉게구름. 폭발에서는 **도넛 모양**으로 열려서
  캐릭터 실루엣이 가운데를 뚫고 올라온다.
- `_chunks` — 회전하며 날아가는 덩어리. 무게감을 담당한다.
- `_shock_ring`, `streak` — 짧고 작게. 숫자를 덮으면 연출 실패다.

판독 구간(`vfx.suppress`)에서는 파티클 수가 30% 수준으로 줄고 대시 먼지는 아예
생략된다.
